# مدرسه جادویی من 🌈 — نمونه اولیه Flutter

این پروژه یک نمونه اولیه قابل توسعه برای اندروید است.

## امکانات موجود
- چند پروفایل مستقل کودک روی یک دستگاه (افزودن، انتخاب، تغییر نام و حذف)
- ذخیره محلی نام، آواتار، ستاره‌ها و درس‌های تکمیل‌شده با `shared_preferences`
- صفحه خانه فانتزی با عروسک‌ها، گل‌ها و کارت‌های رنگی
- فهرست ۱۰ نگاره و ۲۲ درس بر اساس ترتیب جدول پیشنهادی کتاب‌های بارگذاری‌شده
- شنیدن نشانه‌ها با موتور گفتار دستگاه (`flutter_tts` و زبان `fa-IR`)
- صفحه تمرین خواندن و تخته نوشتن با انگشت
- ثبت ستاره برای هر درس

## اجرا
1. Flutter SDK را نصب کنید.
2. در این پوشه اجرا کنید:
   ```bash
   flutter pub get
   flutter run
   ```
3. برای ساخت APK:
   ```bash
   flutter build apk --release
   ```
   خروجی معمولاً در `build/app/outputs/flutter-apk/app-release.apk` قرار می‌گیرد.

## محدودیت‌های آگاهانه نسخه ۰.۱
- محتوای دقیق واژه‌ها، جمله‌ها، تمرین‌های دیکته و نگارش هنوز وارد نشده است؛ از حدس زدن محتوای کتاب خودداری شده و باید صفحه‌به‌صفحه از PDFها استخراج و بازبینی شود.
- بخش «بخوان» فعلاً صدای کودک را ضبط یا ارزیابی نمی‌کند.
- بازی‌ها و آزمون‌های تطبیقی هنوز مرحله بعدی توسعه‌اند.
- قابلیت گفتار فارسی به موتور TTS نصب‌شده روی گوشی وابسته است.
- داده‌ها محلی و مختص همان دستگاه هستند؛ همگام‌سازی ابری وجود ندارد.

## مبنای ترتیب درس‌ها
ترتیب ۲۲ درس و نشانه‌ها از جدول «برنامه پیشنهادی آموزش» در صفحات ابتدایی کتاب فارسی و نگارش بارگذاری‌شده استخراج شده است. زمان‌بندی در خود کتاب پیشنهادی و انعطاف‌پذیر معرفی شده است.
